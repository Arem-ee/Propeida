Longer derivation — any number of steps works

Here's the trick

  1. 1Set the curves equalWhere the integrand crosses, the area is bounded by both curvesx² = 2x
  2. 2Solve for the boundsBring everything to one side and factor out xx² − 2x = 0 → x(x − 2) = 0 → x = 0, x = 2
  3. 3Identify which curve is upperTest a point midway — x = 1: 2(1) = 2 vs 1² = 1, so the line is above2x ≥ x² on [0, 2]
  4. 4Set up the area integralArea = integral of (upper − lower) across the boundsA = ∫₀² (2x − x²) dx
  5. 5Find the antiderivativeIntegrate term by term: ∫2x dx = x², ∫x² dx = x³/3F(x) = x² − x³/3
  6. 6Evaluate at the upper limitSubstitute x = 2 into F(x)F(2) = 4 − 8/3 = 4/3
  7. 7Evaluate at the lower limitSubstitute x = 0 into F(x)F(0) = 0 − 0 = 0
  8. 8Subtract lower from upperThe area is the difference of the two evaluationsA = 4/3 − 0 = 4/3
  9. 9State the answer with unitsAlways carry square units when working with areaA = 4/3 square units
